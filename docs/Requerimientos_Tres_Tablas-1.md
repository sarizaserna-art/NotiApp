# FUNCIONALES

|RF- Funcionales   -  Qué debe hacer el sistema | | | | |
|---|---|---|---|---|
|ID|Nombre|Descripción|Prioridad|Estado|
|RF-01|Autenticar|Permitir que el usuario inicie sesión con correo y contraseña antes de enviar reportes.|Alta|Finalizado|
|RF-02|Registrar|Crear cuentas de usuario solicitando datos básicos y aceptación de la política de privacidad.|Alta|Finalizado|
|RF-03|Validar usuarios|Verificar que solo los usuarios autenticados puedan acceder a funciones de reporte, consulta y edición de información propia.|Alta|Proceso|
|RF-04|Permitir reporte anónimo|Habilitar el envío de reportes sin mostrar públicamente la identidad del ciudadano.|Baja|Proceso|
|RF-05|Solicitar consentimiento|Mostrar un consentimiento explícito antes de recopilar datos personales del usuario.|Alta|Proceso|
|RF-06|Remitir reporte|El administrador pasa las denuncias a las entidades gestoras |Alta|Pendiente|
|RF-07|Guardar reportes offline|Permitir redactar y guardar reportes sin conexión para enviarlos automáticamente cuando vuelva internet.|Alta|Pendiente|
|RF-08|Capturar fotografías|Permitir tomar fotos desde la cámara del dispositivo y adjuntarlas al reporte.|Alta|Pendiente|
|RF-09|Geolocalizar reportes|Obtener la ubicación mediante GPS y usar Wi-Fi o datos móviles como respaldo.|Alta|Pendiente|
|RF-10|Bloquear envíos inválidos|Impedir el envío de formularios con datos inválidos o comportamientos sospechosos.|Alta|Pendiente|
|RF-11|Consultar reportes|Permitir al usuario visualizar los reportes realizados en la aplicación.|Media|Pendiente|
|RF-12|Editar reportes|Permitir modificar la información de un reporte antes de ser enviado.|Media|Pendiente|
|RF-13|Eliminar reportes|Permitir eliminar reportes guardados por el usuario.|Media|Pendiente|
|RF-14|Adjuntar evidencia|Permitir adjuntar imágenes adicionales como evidencia del daño reportado.|Media|Pendiente|
|RF-15|Filtrar reportes|Permitir buscar reportes por fecha, ubicación o categoría.|Media|Pendiente|
|RF-16|Clasificar daños|Permitir seleccionar el tipo de daño o incidente al crear un reporte.|Alta|Pendiente|
|RF-17|Notificar estado|Informar al usuario cuando el reporte sea recibido o actualizado.|Media|Pendiente|
|RF-18|Recuperar contraseña|Permitir recuperar la contraseña mediante correo electrónico.|Alta|Pendiente|
|RF-19|Cerrar sesión|Permitir al usuario cerrar sesión de forma segura.|Alta|Pendiente|
|RF-20|Visualizar perfil|Permitir consultar la información personal registrada en la cuenta.|Media|Pendiente|
|RF-21|Editar perfil|Permitir modificar datos personales del usuario.|Media|Pendiente|
|RF-22|Compartir reportes|Permitir compartir reportes mediante enlaces o plataformas digitales.|Baja|Pendiente|
|RF-23|Confirmar envío|Mostrar un mensaje de confirmación después de enviar un reporte.|Alta|Pendiente|
|RF-24|Detectar ubicación automática|Obtener automáticamente la ubicación actual del usuario al iniciar un reporte.|Alta|Pendiente|
|RF-25|Registrar fecha y hora|Guardar automáticamente la fecha y hora de cada reporte enviado.|Media|Pendiente|
|RF-26|Visualizar historial|Permitir consultar el historial de reportes realizados.|Media|Pendiente|
|RF-27|Generar alertas|Mostrar alertas al detectar incidentes cercanos a la ubicación del usuario.|Media|Pendiente|
|RF-28|Administrar categorías|Permitir al administrador crear, editar o eliminar categorías de reportes.|Alta|Pendiente|
|RF-29|Gestionar usuarios|Permitir al administrador bloquear o habilitar cuentas de usuarios.|Alta|Pendiente|
|RF-30|Exportar información|Permitir descargar reportes en formatos como PDF o Excel.|Media|Pendiente|
|RF-31|Enviar notificaciones|Permitir enviar notificaciones al usuario cuando el estado de un reporte cambie.|Media|Pendiente|
|RF-32|Configurar notificaciones|Permitir que el usuario configure horarios y tipos de notificaciones.|Baja|Pendiente|
|RF-33|Detectar reportes duplicados|Permitir identificar reportes repetidos en una misma ubicación.|Media|Pendiente|
|RF-34|Enviar correo de confirmación|Permitir enviar un correo electrónico con los detalles del reporte realizado.|Baja|Pendiente|
|RF-35|Informar mantenimientos|Permitir mostrar avisos sobre mantenimientos programados del sistema.|Baja|Pendiente|
|RF-36|Remitir reporte|El administrador pasa las denuncias a las entidades gestoras |Baja|Pendiente|
